# สรุปวีดีโอ Facebook ด้วย AI — วิธีที่ง่าย เร็ว ฟรี

วีดีโอหุ้น (กลุ่มปิด) → สรุปใจความสำคัญด้วย AI ฟรี ภายใน ~10 นาที

> **แนวคิด:** ตัดส่วนที่ยุ่งยากทิ้ง (ไม่ใช้ API key, ไม่มี quota, ไม่ถอดเสียงในเครื่อง)
> เหลือแค่ 2 อย่าง: **ดึงเสียง** (script ทำให้) + **ให้ AI ฟรีฟังแล้วสรุป** (เว็บ Google AI Studio)

---

## ขั้นที่ 1 — โหลดวีดีโอจาก Facebook (~2 นาที)

1. ติดตั้ง extension **"Video DownloadHelper"** ใน Chrome
2. เปิดวีดีโอใน Facebook → กดเล่นสัก 2-3 วินาที
3. กด icon extension → ดาวน์โหลดไฟล์ `.mp4`
4. **ย้ายไฟล์ `.mp4` มาวางในโฟลเดอร์เดียวกับ `prep_audio.bat`**

## ขั้นที่ 2 — ดึงเสียง (~1-2 นาที)

ดับเบิ้ลคลิก **`prep_audio.bat`**
- มันจะหาไฟล์วีดีโอ + ดึงเสียงออกมาเป็น `audio_for_ai\audio.mp3` (ไฟล์เล็ก)
- เสร็จแล้วจะเปิดโฟลเดอร์ให้อัตโนมัติ

> ไม่ต้องติดตั้ง ffmpeg เอง / ไม่ต้องใช้ API key / ไม่มี quota

## ขั้นที่ 3 — ให้ AI ฟรีสรุป (~1-2 นาที)

1. เปิดเว็บ **https://aistudio.google.com** (login Google ธรรมดา — ฟรี ไม่ต้องใช้ key)
2. กดปุ่ม **+ / แนบไฟล์** → เลือก `audio_for_ai\audio.mp3`
3. เปิดไฟล์ `audio_for_ai\prompt.txt` → ก็อปทั้งหมด → วางในช่องแชต
4. กด **Run** → ได้สรุปหุ้นทันที (ภาพรวม / หุ้นที่พูดถึง / ตัวเลข / มุมมอง / action / คำพูดเด็ด)

---

## ทำไมวิธีนี้ถึงเวิร์ค (ต่างจากของเดิม)

| ปัญหาเดิม | วิธีนี้แก้ยังไง |
|---|---|
| yt-dlp โหลดกลุ่มปิดไม่ได้ | โหลดเองด้วย extension |
| faster-whisper บน CPU ช้า 30-60 นาที | ไม่ใช้ — ให้ AI ฟังเสียงตรงๆ |
| Gemini API key / quota เต็ม | ใช้เว็บ AI Studio ฟรี ไม่ต้องใช้ API key |
| ติดตั้ง ffmpeg ยุ่งยาก | ใช้ ffmpeg ที่มากับ python package อัตโนมัติ |

---

## ถ้าเจอปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `prep_audio.bat` บอกไม่เจอไฟล์ | เอา `.mp4` มาวางในโฟลเดอร์เดียวกับ `.bat` |
| ไฟล์เสียงใหญ่เกินอัปโหลด | คลิปยาวมาก — แบ่งอัปโหลดทีละครึ่ง หรือบอกผมให้เพิ่มการตัดไฟล์ |
| AI Studio ไม่รับไฟล์เสียง | ลองใช้ https://gemini.google.com แทน (แนบไฟล์เหมือนกัน) |

---

## หมายเหตุ
ไฟล์ `fb_transcribe.py` (เวอร์ชันเก่าที่ใช้ API + whisper) ยังอยู่ในโฟลเดอร์
แต่**แนะนำให้ใช้ `prep_audio.bat`** ตามคู่มือนี้ เพราะง่ายและไม่ติด quota
